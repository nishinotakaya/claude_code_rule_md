# tasks/todo.md

3 ステップ以上の作業は、着手前にここに計画を書く。進捗に合わせてチェックを付け、方針を変えたら理由を 1 行残す。タスクが終わったら内容を消して次に備える。

## テンプレ

```markdown
## <タスク名>（YYYY-MM-DD）

### 要件
- 何を・なぜ・どこまで

### 影響範囲
- 変更ファイル:
- 呼び出し元 / 後続処理:
- 既存テストへの影響:

### 計画
- [ ] STEP 1 ...
- [ ] STEP 2 ...

### 判断の記録
- Codex 第二意見: 採用 / 不採用と理由
- 方針変更: 日時・理由

### 完了条件
- [ ] rspec / build が緑
- [ ] Playwright で受け入れ基準を確認（PC / SP）
- [ ] 秘密情報なし（gitleaks 0 件）
```
