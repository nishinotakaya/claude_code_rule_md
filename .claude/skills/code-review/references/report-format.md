## 「指摘 0 件」は異常ではない

- 「gap を探せ」と指示されたレビュアーは健全でも何かを報告する。そう指示されたからだ。すべての finding を追いかけると過剰設計になる
- 正しさと明示された要件に影響する gap だけを挙げ、残りは optional として扱う
- 迎合対策は件数ではなく「観点網羅の証明」（SKILL.md のセルフチェック）で担保する
