# コメントは 1 行

> コメントは 1 行。2 行目を書いた時点で違反。残すのは非自明な WHY と、差分を可視化する NOTE だけ。

## 書かないもの（削除対象）

| ❌ | 理由 |
|---|---|
| 処理を日本語で言い換えただけの WHAT（`# ユーザーを取得する`） | コードが既に語っている |
| module / class / 関数の頭の長い説明文 | 役割は名前で表す |
| 背景・経緯・出典（「PR#12 指摘」「〜参照」「〜と同じ流儀」） | docs/ や PR・コミットメッセージに書く |
| 型・ループ・代入の説明 | ノイズ |
| `// TODO: あとで直す` | 直すか、Issue にして番号を書くか、消す |

## 残すもの

- 非自明な WHY: なぜこの実装にしたか、コードから読めない判断（例: `# 再ログインしない（レート枠を悪化させるため）`）
- 差分を可視化する NOTE: 何を意図的に変えた／残したかの 1 行
- 外部仕様の罠（例: `// IndexedDB の put は全置換。createdAt を落とすと消える`）

## 形式

- 名詞句か短い 1 文。絵文字・「〜という流儀」「〜のため必須」のような冗長表現を足さない
- 1 行に収まらない = 説明したいことが多すぎる。コメントを削るか、メソッドを分けて名前で語らせる
- 書き終えたら差分の `+` 行のコメントを見直し、2 行以上あれば 1 行に削る
- インターフェースの各フィールドに同じ調子で説明を付けない。名前で分かるものは無言、分からないものだけ 1 行
