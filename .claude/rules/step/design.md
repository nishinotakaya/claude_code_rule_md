# STEP 3: UI/UX 設計（UI 変更がある場合のみ）

PM が「UI 変更あり」と判断した場合、designer を起動する。

## プロンプトテンプレート

```
UI/UX 設計を行ってください。

## 要件
<要件の要約>

## 既存デザインパターン
- フロントは Bootstrap 5 + 自作 CSS（src/index.css のデザイントークン、src/styles/{components,pages}/*.css）
- レイアウトは UserLayout / AdminLayout / ManagerLayout に載せる
- 同じ画面種（一覧・詳細・フォーム・モーダル）の既存実装: <パス>

## タスク
1. コンポーネント構成・レイアウト・配色・間隔・状態（ロード中 / 空 / エラー / 成功）をテキストで定義する
2. /layout-defense §1 の「実装前の 5 問」に答える（min-w-0・折り返し・固定 px・件数 0/1/100・長文）
3. 既存デザイントークンとの整合性を確認する

## 出力形式
- UI 仕様（テキスト）: コンポーネント構造、レイアウト、色・間隔・タイポグラフィ、4 状態
- 既存クラスの再利用一覧 / 新規に必要な CSS（最小限）
- デザインシステム準拠チェック: 違反があれば指摘
```

designer の出力は STEP 5（実装）の入力に含める。
